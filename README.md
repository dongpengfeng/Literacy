# 小小识字岛(https://dongpengfeng.github.io/literacy/)

幼儿认字网页，内置 1300 条字卡（1277 个不同汉字）以及普通话 MP3。无需上传字库。支持范围选择、每轮最多 10 题、错题重答、结果图表、历史统计及 JSON 导出。

## 范围与均衡出题

页面按「选择范围 → 听音答题 → 本次结果」分步展示，错题数据通过顶部导航单独查看。使用 Hash 路由，直接刷新结果页或错题页也兼容 GitHub Pages，无需配置服务器重写。结果页通过轮次编号读取已保存记录；答题中途刷新会返回首页，已答题记录仍保留。

有效的起止位置自动保存在当前浏览器，下次打开恢复上次范围。输入暂时为空、越界或范围内不足 4 个不同汉字时，不覆盖上次有效选择。范围与记录均不跨设备同步。

答题页按动态可视高度布局，题目、四个选项、反馈和下一题按钮在同一屏内，适配手机竖屏与横屏。家长提示和备用朗读收纳在帮助弹窗；首页、结果和错题统计页可以正常滚动。

起止序号从 1 开始且包含端点；先按 JSON 原始条目切片，再去重，1–40 就对应前 40 张字卡。正确答案和干扰项都来自当前范围。范围至少需要 4 个不同汉字，每轮最多 10 个不同目标。预览默认单行省略，可点击展开全部汉字。

普通题优先选历史普通练习作答次数最少的目标字，次数相同随机。没有历史记录的 40 字范围完整做完四轮后，每字都考一次；后续轮次继续保持均衡。已有偏差会优先补齐。计数来自答题记录，刷新后继续有效；旧版没有 mode 的记录按普通练习处理，错题复习不影响均衡计数。只计已经作答的目标字，未答题和干扰项不计数。更换范围时使用相同汉字的全局计数；多个标签页同时开始的未完成轮次不保证互相避让。

## 错题复习与记录

本轮错题及历史待巩固错题均直接复制原错题的 options，**四个字和顺序完全保留**，不重新抽取干扰项。历史复习来自旧题原来的范围，可能与当前新选范围不同；以前旧版本已生成的越界选项也会忠实保留原记录。复习记录保存 sourceRoundId 和 sourceQuestionNumber，用于追溯来源。连续复习仍保留原来的四个选项。

首次选择立即记录，后续点击锁定。答对后移出待巩固列表，历史错误不删除。全部记录继续使用 `literacy.attempts.v1`，同浏览器、同源部署无需迁移旧数据。改变域名、端口或从 file:// 改为 http:// 不共享记录。清理浏览器数据会丢失记录，请定期导出。历史文件导入暂未实现。

导出包含 schemaVersion、exportedAt、attempts 和 mistakeSummary。明细包含轮次、题号、选项、目标汉字、选择、正误、时间、用时、练习类型、范围及来源题号。

## 语音与字库

characters.json 是唯一字库源文件，包含 char、words、sentence，修改后重新构建即可。当前题目只使用 char。audio-data.js 内置 1277 个汉字的 MP3，原生 audio 控件隐藏；点击开始、下一题或听一听直接播放，保留备用系统朗读。手机自动播放限制仍由浏览器决定，可能需要再次点击听一听。多音字使用预生成引擎的默认单字读音。
