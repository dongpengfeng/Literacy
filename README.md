# 小小识字岛

一个无需安装依赖的幼儿听音认字网页。每轮随机抽取最多 10 个不同的目标汉字，每个目标配 3 个不同的干扰项并打乱选项，点击汉字作答。字库至少 10 字时出 10 题，4–9 字时按实际字数出题。同一轮的目标汉字不重复，干扰选项以及不同轮之间允许重复。

## 打开页面

- 直接打开 `index.html`：浏览器通常不允许本地 HTML 自动读取旁边的文件。在“家长小角落”点击“选择 JSON 字库”，选择 `characters.json` 后开始。
- 自动加载字库：在此目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000`。以后替换 `characters.json` 并刷新即可。

朗读使用浏览器自带的语音合成功能，需要系统/浏览器提供中文语音并开启声音。语音可用性、音色和是否依赖网络由浏览器与系统决定；没有声音时，家长可展开“家长辅助读题”。部分多音字的单字发音由语音引擎决定。

## 替换字库

使用 UTF-8 编码保存，格式是严格 JSON（键和值都使用双引号）：

```json
[
  { "char": "一" },
  { "char": "二" },
  { "char": "三" },
  { "char": "四" }
]
```

至少需要 4 个不同汉字。重复项会去重；非汉字或多个字组成的项目会提示错误。可以添加更多项目。练习中手动切换字库只影响下一轮。

## 答题记录与错题统计

每题第一次点击立即记录并锁定答案，点击“下一题”继续。数据保存到当前浏览器当前站点的 `localStorage`，键为 `literacy.attempts.v1`；中途关闭后保留已答记录，下次开始会生成新的一轮，不续答旧题。没有选择答案的题不会计入记录。

记录包含：

| 字段 | 含义 |
| --- | --- |
| `roundId` | 本轮唯一标识 |
| `questionNumber` | 本轮题号（1–10） |
| `options` | 本题四个选项及其显示顺序 |
| `targetChar` | 应选的汉字 |
| `selectedChar` | 实际选择的汉字 |
| `correct` | 是否正确 |
| `answeredAt` | 作答时间，ISO 8601 UTC 格式 |
| `responseTimeMs` | 题目显示至首次选择的时间，毫秒（包含听题、停留时间） |

“家长小角落”展示累计作答、答错次数、正确率、逐字错题统计和最近 20 次作答。统计归属正确答案的汉字，错误率 = 该字答错次数 / 该字作答次数。点击导出可获得全部明细及错题汇总，JSON 含 `schemaVersion`、`exportedAt`、`attempts`、`mistakeSummary`。

记录属于当前浏览器/站点，不会自动同步到其他设备。换浏览器、换端口或从本地文件切换到 localhost 时，记录可能属于不同存储空间；清理浏览器数据会删除记录。建议固定一种打开方式并定期导出。无法读写存储时页面会显示提示，仍可作答和导出本页内的记录。导出的文件供备份和后续统计使用，当前未实现导入历史记录。

## 可视化与错题重答

结果页提供正确率环形图、答对/答错数量和每题的汉字卡片；错题卡片同时显示实际错选的字。家长区提供历史错误率条形图，显示累计答错次数最多的 8 个字，统计包含普通练习与错题复习。

- **再练本轮错题**：仅针对刚完成这一轮答错的目标汉字，重新生成并打乱四个选项；只有 1 个错字时只出 1 题。复习后仍错的字可以继续重答。
- **练习待巩固错题**：取每个汉字最近一次作答仍错误的字，每轮最多 10 字。后续答对即移出待巩固列表，历史错误不会删除。练习进行中暂不允许切换到历史复习。
- 切换字库后，旧字库的错字仍可复习；使用当前字库和历史题目中的汉字补充干扰项。
- 复习会创建新一轮、追加答题记录，不覆盖原答题记录。新增字段 `mode`（`normal` 或 `review`）、`totalQuestions`（本轮总题数）、`sourceRoundId`（本轮错题重答的来源轮次，历史混合复习为 `null`）。兼容之前已保存的记录；旧记录按普通 10 题轮次显示。
